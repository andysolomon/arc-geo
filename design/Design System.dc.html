Interactive Geometry Study Guide

A textbook on screen. Serif type carries the reading. Three hue roles carry the geometry. Everything else stays quiet.

Read like a book. Long measure, 17px text, generous leading, small-caps labels.
Color means something. Green for arcs and correct, violet for angles and selection, orange for horizontal change and bookmarks.
Write in STE. Short active sentences. One idea each. Max 25 words.

Used by the study guide. Tokens live as CSS variables on :root and [data-theme="dark"].

Writing (ASD-STE100)

Procedural sentences ≤ 20 words, command form. Drag point B. Watch the angle.
Descriptive sentences ≤ 25 words, simple present. An inscribed angle has its vertex on the circle.
One topic per paragraph, ≤ 6 sentences. Use the same word for the same thing. Keep articles.
Approved verbs: use, find, make sure, start, test. Not: utilize, ensure, commence, replenish.
